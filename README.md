# Age of Pixel War (proyek Android)

Game RTS isometrik 2D (landscape) dibungkus WebView, offline penuh, tanpa izin INTERNET.
Basis engine sementara: Pixel Empires III: Pocket.

Alur layar: Splash -> Home (PLAY/SETTINGS/CREDITS/EXIT) -> Lobby (pilih bangsa) -> Game.

- Struktur: `docs/STRUCTURE.md` (masih menunjuk struktur lama Pixel Empires III, belum diperbarui)
- Cara build: `docs/BUILD.md`
- Daftar tahap pengerjaan: `docs/ROADMAP.md`
- Audit dan patch bug engine asal: `docs/AUDIT.md`, `docs/PATCHES_CARI_GANTI.md` (belum diterapkan di kode ini)
